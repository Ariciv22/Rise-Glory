# 11 — Legendarny Quest i koniec gry

**Status Kanban:** BACKLOG

## Cel

Stworzyć pełny warunek zwycięstwa Rise & Glory.

Podstawowa droga:

Bohater osiąga minimum 35 Punktów Legendy → odblokowuje Legendarny Quest → podejmuje Legendarny Quest → kończy go → pozostali gracze kończą aktualną rundę → następuje rozstrzygnięcie zwycięstwa → pojawia się „Kronika Waszej Legendy”.

## Punkty do działania

- [ ] Wykrywać osiągnięcie 35 Punktów Legendy.
- [ ] Pokazać komunikat o odblokowaniu.
- [ ] Udostępnić Legendarny Quest.
- [ ] Legendarny Quest nie może być handlowany.
- [ ] Obsłużyć możliwość zmiany dostępnego Legendarnego Questa zgodnie z zasadami.
- [ ] Wieloetapowa struktura.
- [ ] Testy wysokiego poziomu.
- [ ] Ważne decyzje.
- [ ] Walka.
- [ ] Boss lub inne wydarzenie finałowe.
- [ ] Ukończenie Questa.
- [ ] Oznaczenie potencjalnego zwycięzcy.
- [ ] Pozostali gracze kończą bieżącą rundę.
- [ ] Ustalić i zaimplementować rozstrzyganie remisu.
- [ ] Ekran zwycięstwa.
- [ ] Ostatni wpis Kroniki.
- [ ] Ekran „Kronika Waszej Legendy”.
- [ ] Powrót do menu.
- [ ] Możliwość rozpoczęcia nowej partii.

## Definition of Done

Można rozpocząć zwykłą partię Rise & Glory i zgodnie z zasadami doprowadzić ją do pełnego zakończenia i zwycięstwa.
