# 06 — Towarzysz: wspólna wyprawa 2 bohaterów

**Status Kanban:** BACKLOG

## Cel

Rise & Glory pozostaje grą rywalizacyjną, ale dwóch bohaterów może czasowo współpracować. Maksymalnie dwóch bohaterów może tworzyć wspólną grupę. Towarzysze mogą razem podróżować oraz wykonywać wspólne Questy. Współpraca jest tymczasowa.

## Punkty do działania

- [ ] Możliwość zaproszenia drugiego bohatera.
- [ ] Drugi gracz musi zaakceptować.
- [ ] Maksymalnie 2 bohaterów.
- [ ] Ustalić warunek rozpoczęcia współpracy.
- [ ] Preferowany warunek: obaj bohaterowie na tym samym heksie.
- [ ] Status Towarzyszy.
- [ ] Wyraźny UI pokazujący duet.
- [ ] Ustalić sposób wspólnego poruszania.
- [ ] Ustalić zależność od osobnych tur bohaterów.
- [ ] Ustalić sposób rozliczania Akcji podczas wspólnego ruchu.
- [ ] Możliwość rozdzielenia.
- [ ] Możliwość opuszczenia wspólnej wyprawy.
- [ ] Możliwość przyjęcia wspólnego Questa.
- [ ] Quest zapisuje obu uczestników.
- [ ] Etapy mogą być wykonywane przez różnych bohaterów.
- [ ] Nie sumować automatycznie statystyk bohaterów.
- [ ] Bohater z wysoką Walką może wykonywać etap bojowy.
- [ ] Bohater z wysoką Nauką może wykonywać etap badawczy.
- [ ] Ustalić, kto podejmuje decyzję fabularną.
- [ ] Obsłużyć wspólną walkę.
- [ ] Ustalić kolejność ataków bohaterów.
- [ ] Obsłużyć Rany obu bohaterów.
- [ ] Obsłużyć przedmioty obu bohaterów.
- [ ] Obsłużyć Pomocników obu bohaterów.
- [ ] Ustalić konsekwencje porażki.
- [ ] Ustalić podział Złota.
- [ ] Ustalić podział Towarów.
- [ ] Ustalić podział Przedmiotów.
- [ ] Ustalić podział Punktów Legendy.
- [ ] Ustalić sposób rozdzielenia nagrody unikalnej.
- [ ] Przygotować punkt integracji z Kroniką Świata dla wspólnych osiągnięć.
- [ ] Stworzyć przynajmniej jeden Quest zaprojektowany specjalnie dla dwóch bohaterów.

## Ważna zasada

Towarzysz nie może być mechaniką „dodaj statystyki obu bohaterów”.

Przykład:

- Aldric — Walka 6
- Selena — Nauka 6
- Etap 1: Pokonaj strażnika → Aldric
- Etap 2: Odczytaj runy → Selena
- Etap 3: Wspólna decyzja

## Definition of Done

Dwóch bohaterów może stworzyć duet, wspólnie podróżować, ukończyć Quest wykorzystujący specjalizacje obu postaci, podzielić nagrody i później się rozdzielić.
