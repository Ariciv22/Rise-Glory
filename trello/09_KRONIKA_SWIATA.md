# 09 — Kronika Świata

**Status Kanban:** BACKLOG

## Cel

Kronika Świata tworzy historię jednej partii Rise & Glory. Nie jest mechaniką punktową, nie daje bonusów i nie wpływa na wynik gry. Ma zapisywać tylko ważne wydarzenia.

Wpisy są automatyczne, krótkie, chronologiczne i mają lekko kronikarski styl.

## Punkty do działania

- [ ] Stworzyć centralny moduł Kroniki.
- [ ] Każdy wpis zawiera numer rundy.
- [ ] Dodać kategorię wydarzenia.
- [ ] Dodać krótki opis fabularny.
- [ ] Zapisywać nazwy odpowiednich bohaterów.
- [ ] Zapisywać nazwę lokacji, jeśli istotna.
- [ ] Zapisywać nazwę Questa, jeśli istotna.
- [ ] Zapisywać nazwę Wydarzenia Świata, jeśli istotna.
- [ ] Zapisywać powstanie ważnego Zagrożenia.
- [ ] Zapisywać rozwiązanie Zagrożenia.
- [ ] Zapisywać sposób rozwiązania Zagrożenia.
- [ ] Zapisywać ważne Questy.
- [ ] Zapisywać wspólne Questy Towarzyszy.
- [ ] Zapisywać znaczące transakcje podczas Rady.
- [ ] Zapisywać zmianę Poziomu Świata.
- [ ] Zapisywać ważne walki.
- [ ] Zapisywać pokonanie bossów.
- [ ] Zapisywać osiągnięcie warunku Legendarnego Questa.
- [ ] Zapisywać pobranie Legendarnego Questa.
- [ ] Zapisywać ukończenie Legendarnego Questa.
- [ ] Zapisywać zwycięstwo.
- [ ] Podgląd Kroniki podczas gry.
- [ ] Chronologiczna przewijana lista.
- [ ] Rozważyć ikony kategorii.
- [ ] Ekran końcowy „Kronika Waszej Legendy”.
- [ ] Ostatni wpis jasno wskazuje zwycięzcę.

## Czego domyślnie nie zapisujemy

- każdego ruchu,
- każdego rzutu k20,
- każdego sukcesu testu,
- każdej porażki testu,
- zwykłych zakupów,
- zwykłej sprzedaży,
- leczenia,
- treningu,
- użycia przedmiotów jednorazowych,
- nieudanych negocjacji,
- edycji ofert przed ujawnieniem,
- drobnych chwilowych efektów.

## Ważne

Kronika jest warstwą prezentacyjną nad istniejącymi historiami systemów. Nie duplikujemy technicznych logów.

## Definition of Done

Po zakończeniu partii można przeczytać sensowną historię całej rozgrywki od pierwszych wydarzeń do zwycięstwa.
