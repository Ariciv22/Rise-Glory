# 08 — Rada Bohaterów

**Status Kanban:** BACKLOG

## Cel

Rada ma być głównym społecznym momentem Rise & Glory.

## Główny flow

Koniec cyklu rund → Wieści ze świata → Wydarzenie Świata → każdy gracz potwierdza przejście → przygotowanie ofert → odsłonięcie ofert → pełne tury graczy Rady → publiczna oferta → luźny handel → zakończenie tury → kolejny gracz → końcowe podsumowanie → Rada zakończona → wszyscy potwierdzają opuszczenie Rady.

## Punkty do działania

- [ ] Przygotowanie publicznej oferty.
- [ ] Maksymalnie jedna publiczna oferta na gracza.
- [ ] Możliwość wystawienia braku oferty.
- [ ] Cena wyrażona wyłącznie w Złocie.
- [ ] Minimalna cena 1 Złoto.
- [ ] Oferta może zawierać pakiet elementów.
- [ ] Zamrożenie oferty po ujawnieniu.
- [ ] Wspólne ujawnienie ofert.
- [ ] Bohater + panel jego oferty.
- [ ] Jasne oznaczenie „Brak oferty”.
- [ ] Maksymalnie jeden zakup publicznej oferty podczas swojej tury.
- [ ] Zakup nie wymaga ponownej zgody sprzedającego.
- [ ] Sprzedana oferta znika.
- [ ] Sprzedający nadal pozostaje widoczny.
- [ ] Luźny handel.
- [ ] Maksymalnie 2 realnie rozpoczęte negocjacje.
- [ ] Zaproszenie nie zużywa próby, jeśli zostanie odrzucone przed rozpoczęciem.
- [ ] Jedno oczekujące zaproszenie naraz.
- [ ] Timeout zaproszenia.
- [ ] Jedna aktywna negocjacja naraz.
- [ ] Możliwe wielokrotne kontrpropozycje.
- [ ] Pierwszy etap akceptacji: „Wstępnie akceptuję”.
- [ ] Obie strony muszą zaakceptować tę samą wersję.
- [ ] Oferta zostaje zablokowana po obu wstępnych akceptacjach.
- [ ] Drugi etap: „Akceptuj definitywnie”.
- [ ] Obie strony muszą zaakceptować definitywnie.
- [ ] Możliwość „Cofnij do negocjacji”.
- [ ] Cofnięcie kasuje wszystkie akceptacje.
- [ ] Wyposażone przedmioty mogą brać udział w handlu.
- [ ] Ostrzeżenie przed handlem wyposażonym przedmiotem.
- [ ] Towary mogą być oferowane w określonych ilościach.
- [ ] Obsłużyć limity ekwipunku.
- [ ] Ostrzegać o konieczności odrzucenia przedmiotów.
- [ ] Odrzucone przedmioty trafiają na stos odrzuconych.
- [ ] Wspólny Czat.
- [ ] Osobna zakładka Logi handlu.
- [ ] Znacznik nowych wpisów w Logach.
- [ ] Pozostali gracze mogą obserwować negocjacje.
- [ ] Tylko uczestnicy mogą zmieniać ofertę.
- [ ] Lider rozpoczyna Radę.
- [ ] Lider = gracz z największą liczbą Punktów Legendy.
- [ ] Przy remisie wygrywa niższy numer gracza.
- [ ] Po liderze pozostali gracze według numerów.
- [ ] Komunikat „Kolej Gracza X”.
- [ ] Subtelny dźwięk zmiany kolejki.
- [ ] Faza publicznych ofert przed luźnym handlem.
- [ ] Po przejściu do luźnego handlu nie można wrócić do ofert publicznych.
- [ ] Licznik dostępnych negocjacji.
- [ ] Możliwość wcześniejszego zakończenia tury.
- [ ] Ostrzeżenie, jeśli pozostała niewykorzystana negocjacja.
- [ ] Nie można zakończyć tury podczas aktywnej negocjacji.
- [ ] Końcowe podsumowanie udanych transakcji.
- [ ] Nie pokazywać nieudanych negocjacji w podsumowaniu.
- [ ] Ekran „Rada zakończona”.
- [ ] Stały tekst fabularny.
- [ ] Lista gotowości graczy.
- [ ] Status Gotowy / Oczekiwanie.
- [ ] Potwierdzenie gotowości jest nieodwracalne.
- [ ] Po zakończeniu Rady handel jest całkowicie zablokowany.
- [ ] Nadal dostępne Czat i Logi handlu.
- [ ] Po gotowości wszystkich komunikat „Bohaterowie opuszczają Radę”.
- [ ] Krótki fade-out / efekt przejścia.
- [ ] Przygotować punkt integracji z Kroniką dla udanych znaczących transakcji.

## Definition of Done

Pełny cykl Rady można przejść lokalnie od Wieści ze świata do opuszczenia Rady przez wszystkich graczy.
