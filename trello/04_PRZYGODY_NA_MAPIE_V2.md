# 04 — Przygody na mapie V2

**Status Kanban:** BACKLOG

## Cel

Przygody są krótkimi sytuacjami spotykanymi podczas podróży.

- Quest = większe świadomie przyjęte zadanie.
- Przygoda = krótka sytuacja napotkana w świecie.

## Punkty do działania

- [ ] Znaczniki Przygód na mapie.
- [ ] Rozmieszczanie znaczników.
- [ ] Wejście na heks nie rozstrzyga Przygody automatycznie.
- [ ] Gracz świadomie rozpoczyna interakcję.
- [ ] Krótki opis sytuacji.
- [ ] 2–3 możliwości wyboru.
- [ ] Opcje oparte o różne statystyki.
- [ ] Opcja może kosztować Złoto.
- [ ] Opcja może wymagać Towaru.
- [ ] Opcja może wymagać Przedmiotu.
- [ ] Sukces.
- [ ] Porażka.
- [ ] Nagrody.
- [ ] Rany.
- [ ] Złoto.
- [ ] Towary.
- [ ] Przedmioty.
- [ ] Możliwość rozpoczęcia walki.
- [ ] Możliwość otrzymania krótkiego efektu.
- [ ] Usunięcie znacznika po zakończeniu.
- [ ] Przygotować około 10 Przygód do alfy.

## Założenie

Typowa Przygoda powinna trwać kilkanaście do kilkudziesięciu sekund.

## Definition of Done

Podczas podróży bohater napotyka Przygody, dokonuje wyborów i otrzymuje konsekwencje bez konieczności przyjmowania pełnego Questa.
